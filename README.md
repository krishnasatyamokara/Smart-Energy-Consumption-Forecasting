# Smart Energy Monitoring and Predictive Analytics System

This project was developed during Infosys Internship 6.0.

## 📌 Overview
A system to monitor energy consumption and predict future usage using machine learning models.

## ⚙️ Features
- Data Collection & Cleaning
- Feature Engineering
- Linear Regression Model
- LSTM Model for Forecasting
- Model Evaluation

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow / LSTM

## 🚧 Status
This is a prototype and will be improved further.

## 📂 Repository
Contains Jupyter notebooks for each stage of development.
